# Onboard this project

<!-- Stamped by the jig. This is the first session's active plan — following it
teaches the session protocol. -->

## Goal

Turn the freshly-stamped scaffold into a named, oriented project.

## Steps

- [ ] Interview the human briefly: what is this product, for whom, what's the first slice of value? Keep it to a few questions.
- [ ] Fill in `AGENTS.md`: the one-line identity, the stack table, initial invariants. Deltas only — the standard covers the rest.
- [ ] Seed `docs/STATUS.md` (what exists now, what's next) and `docs/ROADMAP.md` (first phase, known deferrals with triggers).
- [ ] Record any founding decisions in `docs/DECISIONS.md`.
- [ ] Confirm the gate runs: `verify` green, hooks installed.
- [ ] Close out: update STATUS, move this plan to `docs/plans/done/`, commit — the same way every future session ends.

## Acceptance criteria

- AGENTS.md has no placeholder text left.
- `verify` is green and a first commit exists.
